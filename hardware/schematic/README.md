| Drawing | Source | What it is |
|---|---|---|

Regenerate with:

## How to read them

One box per part, one row per pin, each pin tied to a named net. Follow a net by its name; the numbers after a name (`>2,4`) are the other sheets it appears on, and the last sheets list every net with all its connections. Colour is the electrical domain: blue system side, amber cable conductors, red network-powered. Dashed purple boxes are the isolation barriers.

## What these are not

- **Not KiCad files and not fabrication-ready.** Pins are named by function, not package pin number. Decoupling, straps, compensation and other datasheet application parts are not drawn. Nothing has been through an electrical rule check, because none exists for this format beyond the domain and pin-use checks in the tools.
- **Not built.** Neither circuit has been assembled or powered.
- The main-board drawing still contains 14 parts with no selected part number (`hardware/bom/bom.csv`).

The next step toward a real board is unchanged: capture these sheets in KiCad with real symbols and pin numbers from each datasheet, then run ERC (`hardware/kicad/README.md`).

## Bench kit: notes before wiring

- The PoE module (sheet 4) shares no connection with anything else. Measure it with a battery multimeter only; do not clip a grounded scope or the Nucleo to it.
- Evaluation-board connector names are functional. Take the real header pins from each board's user guide. The two LAN7801 host generations use different daughter-card connectors.
- Wiremap front-end values are a starting point: 2k2 series protection, 1k/47k source and sense ranges, 1M/47k pin-voltage dividers reading about +/-36 V around a 1.65 V midpoint. Known errors to calibrate out: the 2k2 resistors and the mux on-resistance add to every reading, and the 1M sense resistors sit in parallel with the cable (about 7 % low on the 150 k terminator ID; raise them to 4.7 M if ID 8 misreads).
- Relay coils run from the Nucleo's 5 V pin: about 120 mA with all four on. Power the Nucleo from a port that can supply it.
- Unpowered, the relays connect the cable to the PHY only, as on the product.
